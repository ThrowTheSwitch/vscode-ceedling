    Ceedling for Visual Studio Code

    This Visual Studio Code extension runs your Ceedling test suite from VS Code’s built-in Testing view. It lists every test file, test function, and parametrized case, and runs or debugs any of them from the view or the editor. It also reports failures at their lines, compiler problems in the editor, and code coverage in VS Code’s own coverage views.

    Quick start

    New to Ceedling?

    Ceedling is a build system for C projects that specializes in unit test builds orchestrated around the Unity and CMock projects. Ceedling’s own documentation explains how to set up a project, write tests, and configure builds.

    Most VS Code Ceedling projects need no special configuration. Install the extension, open your Ceedling project’s folder, and the Testing view lists your tests.
