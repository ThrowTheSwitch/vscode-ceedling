# Releases

Four running documents in the extension’s repository track its releases. The links below to those documents include the current and complete text across all extension versions.

The version selector in this site’s header is pinned to each minor release (e.g. 2.1.0) but covers all patch releases for that version.

<div class="grid cards" markdown>

-   :material-format-list-bulleted: **[Changelog][changelog]**

    ---

    The terse, itemized record of what changed in each release. Read it to find when a feature or fix arrived.

-   :material-newspaper-variant: **[Release Notes][release-notes]**

    ---

    The narrative version, with each release’s highlights. Read it before upgrading.

-   :material-alert-octagon: **[Known Issues][known-issues]**

    ---

    The open problems, by the Ceedling versions they affect. Read it before reporting a bug.

-   :material-swap-horizontal: **[Breaking Changes][breaking-changes]**

    ---

    What needs action when upgrading across a compatibility boundary. Read it when an upgrade changes behavior you rely on.

</div>
